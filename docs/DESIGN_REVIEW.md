## Направление

Рабочий портал для сотрудников игровой фракции. Основной путь нового сотрудника — открыть курс. Для остальных важен быстрый поиск материалов и инструментов.

Тёмно-синяя тема, Manrope, сохранённое фото патрульного автомобиля. Самая выразительная часть — первый экран. Остальной интерфейс спокойный. Не добавляем вымышленные отзывы и показатели.

Палитра возвращена к прежним цветам по просьбе пользователя: фон #020617, поверхность #081B36, поднятая поверхность #0D2A50, текст #ECF5FF, вспомогательный текст #A6BCD8, голубой акцент #7DD3FC и синие кнопки #2563EB. Компоновка, типографика и жидкое стекло сохранены. Размеры шрифта и интервалы следуют шкале landing-page-design.

Шапка — отдельный стеклянный остров. Меню и поиск — native dialog с ограничением фокуса, Escape и возвратом фокуса. Переходы — ссылки с сохранением History API.

Жидкое стекло: отдельный оптический слой, blur, насыщенность, внутренние блики и SVG displacement по принципу Liquid Glass Studio. Текст не искажается. Небольшие оптические поверхности размещаются поверх фотографии; остальные панели используют умеренное матовое стекло. Предусмотрены fallback и reduced transparency.

Композиция: первый экран → поиск → курс → рабочие инструменты → короткий тезис → подвал.

## Движение

Контекст website. Фото и поверхности неподвижны. Содержимое первого экрана появляется в порядке чтения; карточки один раз входят при 30% видимости через IntersectionObserver/Framer Motion. Текстовые карточки без циклических историй. Реальные показатели не заменяются демонстрационными числами.

Меню отвечает на действие пользователя, hamburger плавно превращается в X. Уменьшенная анимация показывает конечное состояние. Экспорт видео не требуется.
