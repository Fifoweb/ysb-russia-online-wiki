# Загрузка скриншотов на Allwebs

В полях скриншотов и доказательств доступны выбор файлов, перетаскивание и
вставка изображения через Ctrl+V. Обычная вставка текста и готовых ссылок
сохраняется. Изображения загружаются сразу после выбора, после чего оригинальная
ссылка добавляется в поле. Отправка отчёта блокируется до завершения загрузок
и разрешения ошибок. Удаление файла из списка убирает его из формы, без удаления
с фотохостинга и из уже отправленных отчётов.

Поддерживаются PNG, JPEG и неанимированный WEBP до 10 МиБ и 40 мегапикселей.
Файлы проверяются по содержимому на сервере, исходные байты не перекодируются.
Для ачивок сохраняется лимит 50 ссылок; в остальных полях действуют их прежние
ограничения длины и количества. Поле ссылки на полный отчёт в Discord остаётся
обычным полем ссылки.

`upload-evidence-image` требует действующую сессию сайта и подтверждённую
идентичность Discord. Он принимает один бинарный файл, а не JSON заявки.
API-ключ хранится только в Supabase Secrets как `ALLWEBS_API_KEY`.
Запросы к хостингу отправляются только на фиксированный HTTPS API Allwebs.
Исходное имя пользовательского файла на хостинг не передаётся.

Лимиты загрузчика независимы от таймеров подачи отчётов: 60 запросов в минуту
на аккаунт и 240 суммарно, 200 МиБ принятых данных в сутки на аккаунт и 2 ГиБ
суммарно. В браузере одновременно выполняются две загрузки; обработчик также
ограничивает параллельность для соблюдения бюджета памяти. Лимиты не заменяют
защиту внешнего шлюза от сетевого флуда.

Приватный кеш по SHA-256 повторно использует ссылку для идентичных файлов.
Это сохраняет существующую проверку повторных доказательств по URL и избегает
повторного обращения к Allwebs. Неопределённый результат отправки блокирует
повтор на 24 часа: сервер повторяет только запись результата в базу, а не
загрузку изображения. При ошибке можно убрать файл и вставить готовую ссылку.

Allwebs допускает временные игровые скриншоты и не гарантирует постоянный архив.
Интерфейс показывает фактический срок хранения, если хостинг его вернул.
На контрольных загрузках 3 ноября 2026 гостевой API вернул срок до ноября 2027;
параметр короткого срока при контрольной загрузке не изменил результат.
Оригиналы следует сохранять у себя. Истечение срока или удаление файла на
Allwebs не удаляет сам отчёт из Discord.

Развёртывание: применить миграции, настроить `ALLWEBS_API_KEY`, развернуть
`upload-evidence-image` и обновлённый `submit-academy-promotion-report`, затем сайт.
Проверки: `tests/evidence-upload.test.ts`, откатываемая транзакция
`supabase/tests/evidence_uploads.sql`, общий `npm run test:security`.
Контрольные публикации допускаются только для нейтральных тестовых изображений;
для проверки отчётов используются подмены Discord, без реальной отправки.
