# Загрузка скриншотов

В полях скриншотов и доказательств доступны выбор файлов, перетаскивание и
вставка изображения через Ctrl+V. Обычная вставка текста и готовых ссылок
сохраняется. Сначала пользователь собирает подборку, затем нажимает
«Загрузить выбранные». До отправки показываются количество фото и хостинг:

- до 10 фото включительно — отдельные изображения Allwebs;
- от 11 до 50 фото — альбомы Fotora.

Количество пересчитывается и при выборе несколькими порциями. Снимки, уже
загруженные ранее в этой форме, не переносятся; для новых учитывается общее
количество выбранных фото. Повторные доказательства используют исходную ссылку
из общего кеша независимо от хостинга, без повторной публикации.
Ссылка на альбом повторно выдаётся только его владельцу; один совпавший снимок
не раскрывает подборку другого аккаунта.
Готовый альбом автоматически подставляется только тогда, когда выбраны все
его фото. При выборе части снимков возвращается подсказка для ручной проверки,
чтобы в отчёт не попали невыбранные изображения из старого альбома.

Ссылки автоматически добавляются в исходное поле; введённый вручную текст
сохраняется. До загрузки выбранных файлов, окончания запросов и разрешения
ошибок отправка отчёта заблокирована. Удаление альбома из формы убирает его
ссылку, без удаления файлов с хостинга или из отправленных отчётов. Одинаковая
ссылка остаётся, пока на неё ссылается другая группа файлов в этой форме.

Поддерживаются PNG, JPEG и неанимированный WEBP до 10 МиБ и 40 мегапикселей.
Общий размер подборки — до 100 МиБ; в одиночном поле принимается один снимок.
Файлы проверяются по содержимому на сервере, исходные байты не перекодируются,
исходные имена на внешние хостинги не передаются. Большие подборки Fotora
делятся на альбомы по 20 МиБ для соблюдения бюджета памяти сервера.
В обычном поле сохраняется прежний лимит ссылок и длины; несколько фото одного
альбома занимают одну ссылку. Для ачивок сохраняется лимит 50 ссылок.

Оба обработчика требуют действующую сессию сайта и подтверждённую идентичность
Discord. `upload-evidence-image` принимает один бинарный файл; API-ключ Allwebs
хранится только в Supabase Secrets как `ALLWEBS_API_KEY`. Multipart-тело полностью
формируется до отправки; отдельный HTTP-клиент закрывается после чтения ответа.
Перед отправкой проверяется соединение: до трёх HEAD-запросов по пять секунд.
Если соединение недоступно, файл не отправляется и ручной повтор доступен сразу.

`upload-evidence-album` принимает multipart с `files` и `selectionCount`.
Один запрос — до 20 МиБ изображений и до 21 МиБ с multipart-заголовками.
Fotora обрабатывается через обычную гостевую форму: загрузка, просмотр черновика,
создание альбома и проверка публичной галереи. Куки существуют только в памяти
обработчика; HTML и JavaScript хостинга не выполняются. При изменении формы или
появлении активной капчи загрузка останавливается. Публичной документации API
у Fotora на момент интеграции не найдено; совместимость формы проверяется
протокольными тестами. Ключ Fotora или вход пользователя на Fotora не нужны.

Лимиты независимы от таймеров подачи отчётов: 60 запросов в минуту на аккаунт,
240 суммарно, 200 МиБ принятых изображений в сутки на аккаунт и 2 ГиБ суммарно.
Клиент выполняет до двух загрузок Allwebs или один альбом Fotora одновременно
в поле. Сервер допускает две бинарные загрузки или один альбом на worker.
Эти лимиты не заменяют защиту внешнего шлюза от сетевого флуда.

Приватный кеш SHA-256 общий для обоих хостингов. После неопределённого результата
завершённой попытки ручной повтор разрешён через минуту; незавершённый запрос
другого обработчика сохраняет защиту от параллельного повтора. Автоматически
повторяются только безопасная проверка соединения и запись результата в базу,
а не отправка файлов или создание альбома.

Оба хостинга — временное внешнее хранение. Интерфейс показывает фактический срок,
если он указан. На контрольных загрузках 3 ноября 2026 Allwebs вернул срок до
ноября 2027, а Fotora — до 4 декабря 2026. Оригиналы следует сохранять у себя.
Истечение срока или удаление файлов на хостинге не удаляет сам отчёт из Discord.

Развёртывание: применить миграции, настроить `ALLWEBS_API_KEY`, развернуть
`upload-evidence-image` и `upload-evidence-album`, затем сайт. Оба обработчика
публикуются с JWT-проверкой. Старый `submit-academy-promotion-report` уже принимает
Fotora и Allwebs; маршруты и роли Discord при этой интеграции не меняются.

Проверки: `tests/evidence-upload.test.ts`, `tests/evidence-album.test.ts`,
`tests/evidence-upload-ui.test.ts`, откатываемая транзакция
`supabase/tests/evidence_uploads.sql`, общий `npm run test:security`.
Реальные загрузки допустимы только для нейтральных тестовых изображений;
для проверки отчётов используются подмены Discord без реальной отправки.
